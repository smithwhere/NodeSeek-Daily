# NodeSeek 每日签到、随机评论与免费投喂

每天北京时间 00:05 由 GitHub Actions 主触发，05:00、10:00 再进行补跑检查，也可在 Actions 中手动 Run workflow。
定时、补跑和手动 Run workflow 共用北京时间当天的进度：评论累计最多 3 帖，投喂数量按服务器剩余免费额度决定。每次运行都重新查询免费额度，只继续未完成的评论和剩余免费投喂。
补跑复用加密状态；当天已完成 3 个帖子的评论时不会重复发送，部分完成时只补足剩余额度。GitHub 定时触发可能延迟或遗漏，无法保证精确到分钟。
先固定领取 5 鸡腿，再在交易区随机选择 3 个不同的可评论帖子，每个帖子独立从已导入的 39 条评论中随机选一条，连续两次评论发送之间至少间隔 10 秒。
每日再从交易区随机选择不同帖子，各免费投喂 1 个鸡腿，持续投喂至服务器剩余免费额度用完；不再固定限制为 2 个。

## Secrets

在 Settings → Secrets and variables → Actions 保存：
- `NS_USERNAME`：NodeSeek 用户名
- `NS_PASSWORD`：NodeSeek 密码
- `YESCAPTCHA_KEY`：YesCaptcha API 密钥
- `COOKIE_ENCRYPTION_KEY`：专用 Fernet 加密密钥，不应删除或随意更换
- `NS_COOKIE`：可选，有效 Cookie 优先使用；失效时重新登录

首次运行没有 Cookie 时使用账号密码登录。如果 NodeSeek 要求邮箱/短信验证新设备，脚本会停止并提示先配置已登录的 `NS_COOKIE`，不会把验证跳转误报为成功。此状态会加密写回，后续跳过付费登录，直到更新 `NS_COOKIE`。之后优先读取 `.state/nodeseek.enc` 中的加密 Cookie，失效后才重新登录。
持久化文件长期保留，不设置客户端到期时间；实际会话是否有效由 NodeSeek 服务端决定。服务端失效后自动重新登录和更新。
新 Cookie 用专用 Secret 加密后立即写回仓库，并重新读取、建立 Cookie 会话后继续签到。
写回使用工作流的 `GITHUB_TOKEN`（仅需 contents: write），无需个人访问令牌。
评论和免费投喂分别记录进度，每次确认后立即加密保存已完成的帖子 ID；补跑只补足剩余额度，跳过这些帖子。提交状态不明时停止，避免重复发送。

用户名密码登录通过 YesCaptcha Turnstile 服务，可能消耗服务余额。
密码、API 密钥和 Cookie 不写入代码、日志或公开文件。

## 评论设置

每天累计评论交易区 3 个不同的帖子，每帖只发一条。随机打乱交易区第一页的候选帖子，跳过置顶、只读、标题标有已出/已收及自己已发帖或评论的帖子，再选足 3 个；可评论帖子不足时保留进度，等待补跑继续。
默认随机评论列表已导入 `评论内容.txt` 的 39 条内容，一行一条，每个帖子独立随机选择其中一条，不同帖子可能选到相同的内容。
可用仓库变量 `NS_COMMENT_TEXTS` 自定义，例如：
```json
["帮顶一下，祝早日成交。", "支持一下，祝交易顺利。"]
```
评论应遵守论坛版规。同一天手动重复运行只补足剩余额度，已完成 3 条时直接跳过。旧版仅记录当天完成日期的单帖任务会迁移为已完成 1 条，再补足 2 个其他帖子；是否完成按当天累计条数判断，不再只依赖日期标记。先执行评论，再检查免费投喂额度，避免投喂失败阻止评论。
如要仅签到，将工作流的 `NS_COMMENT` 改为 `"false"`。

## 免费投喂设置

按服务器返回的 `maxFreeLike - freeLikeUsed` 剩余免费额度投喂：从交易区第一页随机选择不同的帖子，给楼主的主帖各投喂 1 个，直到免费额度用完。网页等其他途径已使用的额度也计入服务器用量；旧版当天已完成 2 个的记录不会阻止继续使用剩余额度。可投喂帖子不足时保存进度，等待补跑继续。跳过置顶、只读、已出/已收、自己的帖子、已投喂及发布满 7 天的帖子，两次连续投喂至少间隔 10 秒。
每次发送前重新检查服务器的免费额度；没有免费额度时跳过，不主动尝试付费投喂。投喂成功后核对免费额度用量增加 1、账户余额未减少，再保存进度。结果不明时停止，当天补跑不重复提交。
NodeSeek 的同一个投喂接口会在免费额度用完时扣除余额，当前网页投喂请求未提供“仅免费”提交参数。投喂期间请勿同时在网页消费免费投喂额度，以免并发操作导致平台转为扣余额。
设置工作流 `NS_FEED: "false"` 可单独关闭免费投喂；评论与投喂可以分别开启或关闭。

## 验证

工作流只有在签到、当天 3 条评论及免费投喂均完成（或剩余免费额度不足而跳过）时显示绿色；提交评论后状态不明时不会再次发送。
评论通过 NodeSeek 页面使用的评论接口提交，再读取帖子核实作者和正文；请求被 Cloudflare 拦截或提交结果不明时停止，保留已加密的会话。
GitHub 定时任务可能延迟，公开仓库长期无活动时平台可能暂停定时执行。
